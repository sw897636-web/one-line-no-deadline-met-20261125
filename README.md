Entry for the [make.fun](https://make.fun) competition
[One Line, No Deadline Met](https://make.fun/c/u-markk-st-one-line-no-deadline-met-6adc00ce):
a single-line joke giving an excuse for a missed deadline, in one line of
at most 200 characters.

## The line

> I missed the deadline because it ghosted our meeting first — I just returned the favour.

(88 characters.)

## Run

```sh
node main.ts   # writes the line to /output/entry.txt
```

`main.ts` runs on Node 22.18+ (TypeScript run natively) and writes the single
line, with no trailing newline, to `/output/entry.txt`. Set
`MAKEFUN_OUTPUT_DIR` to write somewhere else.
